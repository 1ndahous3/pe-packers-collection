# PE Packers Collection

A collection of popular and rare PE packers, with useful resources for finding, studying and using them: an index, source and download links, research notes, available tools and packed examples.

The [shared benign PE fixtures](fixtures/README.md) support reproducible packing experiments across x86/amd64 × EXE/DLL. One application is testing static, dynamic and emulation-based unpackers.

See the [template guide](templates/README.md) for the packer directory layout and [collection conventions](CONTRIBUTING.md) for adding and verifying cases.

## Packer indexes

One entry represents a family or tool; versions and options belong to its cases. Each custom implementation receives its own ID when research begins. The reserved custom label remains outside the indexes. Packer categories are provisional.

- **Known:** an identified tool, source implementation, developer product or documented packing workflow provides a potential route to packing or protecting your own PE. Local execution does not have to be verified yet.
- **Partially known:** independent material exists, such as unpacking scripts, research or historical descriptions, but a tool or workflow for packing your own PE has not been established.
- **Unknown:** only detector evidence has been established in this review. This is a review result, not a claim that independent materials cannot exist.

A historical name, support page, archive member listing or unpacking script alone is insufficient for Known. The **Material** column identifies the available evidence. Historical tools can qualify when a packing implementation or workflow is identified. Verification is specific to each research entry; index inclusion alone does not establish a working build or successful packing run.

The **Directory** column links to existing packer directories. Leave it empty until a directory is created for concrete research or testing.

Sources prefer official websites/repositories and manuals, then direct historical or research material. Detector categories alone do not prove runtime behavior. Named malware-specific packers are excluded.

See [sources and research notes](sources.md) for public collections, acquisition leads and index decisions.
